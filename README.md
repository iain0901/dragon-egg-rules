# 龍蛋迷蹤戰規則動畫網頁

## 使用方式

1. 解壓縮 ZIP。
2. 直接用 Chrome、Edge 或 Safari 開啟 `index.html`。
3. 按「播放」即可自動播放約 30 秒。
4. 可用畫面按鈕切換、暫停或重播。
5. 投影時建議按瀏覽器全螢幕（Windows：F11；macOS：Control＋Command＋F）。

## 操作

- 播放／暫停：畫面按鈕或空白鍵。
- 上一頁／下一頁：畫面箭頭或鍵盤左右鍵。
- 重播：回到第一頁並重新自動播放。

## 規則內容

- 每家 3 位進攻者、1 位防守者。
- 三顆龍蛋為 3、5、10 分；位置交換後再開始。
- 進攻者蒙眼、單腳小跳，每跳一步前擠壓尖叫雞。
- 防守者蒙眼並固定於防守區，依雞聲使用海綿棒輕碰。
- 被碰到、另一腳違規落地或沒有讓尖叫雞發聲，回起點。
- 每輪約 3 分鐘，共 4 輪；累積總分最高之家獲勝。
